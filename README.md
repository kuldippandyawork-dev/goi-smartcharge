# GOI SmartCharge

An AI-powered EV Charging Route Optimization Platform.

## Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS

## Project Goal

Build an intelligent EV route planner that recommends the best charging stations based on:

- Battery level
- Route distance
- Charging station occupancy
- Waiting time
- Future AI demand prediction
